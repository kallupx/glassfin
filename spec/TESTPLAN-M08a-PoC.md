# Test plan – M08a-PoC (playback for the PoC tier: DirectPlay + minimal DirectStream)

**Author:** Testaaja · 2026-10-27 · **Based on:** spec/08-playback.md, 02-state-errors-performance.md, 03-security.md, 04-auth.md, 06-home.md, 07-library-detail.md, SPEC.md and spec/adr/M08-2.md on `main` (`9f374df`, v1.3.3 plus PR #17/#18, v1.3.4 parts), TESTPLAN-ADR-M08-2.md (master copy incl. T08-2-51), and the PoC scope agreed in the Glassfin group on 2026-10-27 (Spesifikaatio, Turvallisuus, Tutkija, Koodari; reference `PoC 10-27`). The PoC tier itself is **not yet in SPEC.md on `main`**; Spesifikaatio records it in a separate spec PR (Q8P-01).
**Scope (PoC 10-27):** DirectPlay of MP4/MOV/M4V/HLS with H.264/HEVC video and AAC/AC3/EAC3 audio · DirectStream of other containers (MKV) as a server HLS remux with fMP4 segments, video copied · unsupported audio (DTS/TrueHD) → the server transcodes **only the audio** to AAC or EAC3 · a **static, hardcoded** DeviceProfile · unsupported video (MPEG-2, VC-1) → localized error "This video format isn't supported yet", playback never hangs · `AVPlayerViewController` · tokens via the M08-2 resource loader (Authorization except the D4 server-query-only HLS playlist path, Q8P-23) · Playing/Progress/Stopped via `CoreNetworking` · logs only via `MediaLogRedactor`. **Out of scope:** video transcoding, subtitles, track selection, trickplay, media segments, the next-up timer, the full runtime DeviceProfile, device measurements P1–P15 (optional device rows are marked "optional").
**Environment:** Testaaja runs Linux. Mac tests run in CI (`test-tvos`, `test-ios`, `full-ui`), and Testaaja reads the artifacts (JUnit, PNG, xcresult). **X** rows run against the in-test mock HTTP(S) server. Rows whose scenario says "(macOS server)" run on a **hosted macOS runner against a native macOS Jellyfin server started beside the simulator** (group decision 2026-10-27, QPOC-02 resolved); evidence is the xcresult plus a screen recording, both uploaded as CI artifacts. The runner uses the macOS arm64 Jellyfin builds from repo.jellyfin.org for **all three versions** (10.10.7 from the archive URL, 10.11.11, and 12.2 from tag `v12.2`); jellyfin-ffmpeg is installed separately and passed with `--ffmpeg` (Q8P-20 resolved). **I** rows check the server side only (PlaybackInfo, `TranscodingUrl`, `/Sessions` `TranscodingInfo`, UserData) from Linux; AVPlayer is not involved. Device rows are done by Koodari or kallut (SPEC §8 R7).
**Test media:** files F1–F6 in Appendix A (seed for the macOS servers and the Linux API matrix, ffmpeg `testsrc2`, generated per run, never committed; `Tests/Media/README.md`). **F1 and F3 are about 60 s** (resume and Progress cadence); F2, F4, F5 and F6 stay under 10 s. The bootstrap sets `MinResumeDurationSeconds=0` via `/System/Configuration` (Q8P-08 resolved); the server still applies `MinResumePct` (5 %) and `MaxResumePct` (90 %). F1–F5 are Spesifikaatio's minimum; F6 is optional.

**References:** `08 Start kn` = "Playback start" item n · `08 DP` = DeviceProfile section · `08 View` = playback view and the Siri Remote · `08 PBn` = feature table · `08 HK` = acceptance criteria · `08 v1.3.3` = clarifications Q8-2-01 · `ADR Dn` = spec/adr/M08-2.md decision n · `02 §n` / `02 Pn` / `02 v1.3.2` = 02-state-errors-performance.md · `Sx.y` = 03-security.md · `Q8-2-nn` / `T08-2-nn` = TESTPLAN-ADR-M08-2 · `Q4-nn` = TESTPLAN-M04 decisions · `PoC 10-27` = group decision of 2026-10-27 · `Fn` = Appendix A media. (Short codes k and HK are kept as reference codes.)
**Run:** **L** = Linux `swift test` (GlassfinCore only: profile builder, method selection, `TranscodeReasons` parser, report payloads, tick math, redactor) · **X** = macOS XCTest (mock HTTP(S) server, AVPlayer in the simulator) · **U** = macOS XCUITest (`XCUIRemote`; mock server `-uitest-mock-server`, or "(macOS server)" = native macOS Jellyfin on the hosted runner) · **S** = snapshot (1080p + 4K) · **I** = Linux Docker integration (`integration.yml`, 10.10.7 / 10.11.11 / 12.2; ⚠️ 12.2 bootstrap currently fails with "library scan found no movie") · **K** = review or CI lint script · **M** = manual device test.
**🔒** = raised to Turvallisuus (traceable to 03-security.md).
**[Release]** in a scenario (after 🔒 if present) = the row runs on the **Release** build configuration (token rows: the segment-credential conditions of Q8P-15, the 401 path and log redaction; QPOC-09 resolved). All other rows may run on Debug.
**UI strings and assertions:** expected UI texts are given as the English dev-language string (`Localizable.xcstrings`) with the Finnish localization in parentheses. X and L tests assert on `PlaybackState`, `AppError`/`PlaybackError` or the String Catalog key, never on a hardcoded string. U and S tests run in the `en` locale unless the row says `fi`.
