# Test plan – M02 (state management, error handling, cache and performance)

**Author:** Testaaja · 2026-10-27 · **Based on:** spec/02-state-errors-performance.md on `main` (`a40ded9`; v1.3.2 clarifications, PR #17 copy alignment and the PR #18 v1.3.4 "server down while content is already on screen" rule), 03-security.md, 04-auth.md (Q4-10, Q4-11), SPEC.md. **Code under test:** PR #7 at `acba693` (`Packages/GlassfinCore/Tests/CoreStateTests/T02FoundationTests.swift`, `T02BehaviorTests.swift`, `Tests/CoreNetworkingTests/StringCatalogTests.swift`).
**Environment:** Testaaja runs Linux. Mac tests run in CI (`test-tvos`, `test-ios`, `full-ui`), and Testaaja reads the artifacts (JUnit, `swift-test.log`, PNG). The `lint` job also runs the Linux package tests (`scripts/coverage-gate.sh`). Device measurements (P1–P15 absolute targets) are done by Koodari or kallut (SPEC §8 R7) and are out of scope for the PoC.
**ID rule:** one test ID = one test method. The method name carries the ID (`testT02_nn_…`). IDs T02-01…T02-30 keep their current method names. The four duplicate-suffix tests (`…08b`, `…09b`, `…18b`, `…19b`) are renamed to T02-31…T02-34 (Appendix A). T02-35…T02-38 are new and **not yet implemented** in `acba693`.

**References:** `02 §n` = section n of 02-state-errors-performance.md · `02 §3 table/<row>` = a row of the §3 error table · `02 v1.3.2` = "Clarifications v1.3.2" · `02 v1.3.4` = the "server down while content is already on screen" bullet under the §3 table (`main` line 60, PR #18) · `02 Pn` = performance metric n · `02 HK` = module acceptance criteria · `Sx.y` = 03-security.md · `04 Q4-nn` = 04-auth.md decisions.
**Run:** **L** = Linux `swift test` (the `lint` job) · **X** = macOS XCTest (`test-tvos`, `test-ios`) · **U** = macOS XCUITest (`XCUIRemote`, mock server `-uitest-mock-server`) · **K** = review or CI lint script · **M** = manual device test.
**🔒** = raised to Turvallisuus (traceable to 03-security.md).
**UI strings and assertions:** expected UI texts are given as the English dev-language string (CoreModels `Localizable.xcstrings`) with the Finnish localization in parentheses. L and X tests assert on state, `AppError`, or the String Catalog key. Text-level rows (T02-36…T02-38) assert the resolved text: on Linux `text == key` (no catalog lookup); on Apple `text ==` the catalog's `en` value. U tests run in the `en` locale.
